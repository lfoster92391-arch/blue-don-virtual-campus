## Purpose

Blue Don will grow. Without a framework, it becomes a pile of features. These **six strategic pillars** provide a decision filter for every future idea:

> **"Which pillar does this belong to?"**  
> If it doesn't fit one of them, it probably doesn't belong in Blue Don.

### Pillar 1 — Student Success

**Academics, growth, portfolios, career readiness.**

| Includes | Examples |
|----------|----------|
| Academies & learning engine | Modules, labs, certifications |
| My Journey | Goals, reflections, resume, **full Madonna Journey** |
| Future Center | Career quiz, colleges, trades, scholarships |
| Opportunity Center | Actionable feed, What If?, bucket list, Blue Don Connect |
| Character & Legacy | Daily challenges, virtue wheel, quests, Hall of Legacy |
| Daily Discovery | Daily learning cards, Catholic Corner, Today I Learned |
| Campus Challenges | Monthly seasons, Mystery Monday, champion banners |

## Feature Evaluation Checklist

Before adding any feature:

| # | Question |
|---|----------|
| 1 | **Which pillar?** (Primary; secondary allowed) |
| 2 | **Which module?** (Product Blueprint placement) |
| 3 | **Which nav destination?** (Digital Campus IA) |
| 4 | **Student-first?** (Constitution Article VI) |
| 5 | **Does it duplicate an existing flow?** (Prefer Blue Don Requests) |
| 6 | **School-agnostic?** (Works for tenant #2+) |

If a feature spans pillars (e.g., event check-in), designate **primary pillar** and document integrations.
