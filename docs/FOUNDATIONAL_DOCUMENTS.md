## Approval Gate

No Phase 17+ feature code without:

1. Constitution alignment (student-first, privacy, AI boundaries)  
2. Product Blueprint module placement (A1)  
3. Technical Architecture data + permission plan (A2–A3)  
4. User Experience Flow alignment (entry point, tap count, auto-updates)  
5. Digital Campus IA placement (nav destination, section ownership)  
6. Broadcasts alignment (audience, approval, priority) — when touching communications  
7. Strategic pillar fit — which of the six pillars owns this feature?

See [Strategic Pillars](./BLUE_DON_STRATEGIC_PILLARS.md), Constitution Article XIII, Product Blueprint § Build Discipline, UX Flow Part XVI, Digital Campus Part I, and Broadcasts Part XVI.
