## Executive Summary

Students compete for attention with TikTok, YouTube, Instagram, Snapchat, Roblox, and games. If Blue Don is only "school," they'll use it because they **have to**. If Blue Don is **fun**, they'll open it because they **want to**.

**Blue Don Arcade** delivers daily brain games, weekly tournaments, educational simulators, escape rooms, and **Campus Quest** — a QR scavenger hunt that turns the physical school into a game board.

> *"I don't want to lose my 47-day streak, and I want to see today's puzzle."*

**Module 39** · **Routes:** `/arcade`, `/arcade/games`, `/arcade/quest`, `/arcade/tournament`

## Part I — Platform Identity

| Concept | Definition |
|---------|------------|
| **Blue Don Arcade** | Games hub — play, learn, earn |
| **Daily Brain Games** | New puzzles every day — Wordle, trivia, IT, faith |
| **Arcade Streak** | Consecutive days played — Duolingo-style retention |
| **Weekly Tournament** | Friday Trivia Night — top 10 rewards |
| **Educational Games** | Learning disguised as play — FAFSA, adulting, careers |
| **Campus Quest** | QR scavenger hunt across physical campus — **killer feature** |
| **Prize Wheel** | Spin after 3 games — coins, XP, badges, coupons |
| **Escape Room** | Monthly narrative puzzle adventure |

### vs. other daily modules

| Module | Feel | Example |
|--------|------|---------|
| Daily Challenge (36) | Do good | Help someone with tech |
| Daily Discovery (37) | Read & learn | Saint of the Day card |
| Campus Challenges (38) | School together | Kindness Month |
| **Arcade (39)** | **Play** | BlueDonle, Campus Quest, Adulting sim |

### Engagement principles (Duolingo model)

| Principle | Arcade implementation |
|-----------|----------------------|
| **Streaks** | Daily brain game streak — loss aversion |
| **XP** | Every puzzle, every quest stop |
| **Friendly competition** | Class tournaments, future school vs school |
| **Small daily wins** | 5-minute games, not hour-long sessions |
| **Constant progression** | Levels, badges, unlockables |

### Constitution alignment

- Fun serves **learning and growth** — not empty addiction (Article VI Student-First).  
- No loot boxes with real money. Coins earned, not purchased by minors.  
- Streak forgiveness: one "streak freeze" per month (configurable).  
- Catholic content (Bible Wordle, saints) respectful — Campus Ministry review.

## Part XIII — Data Model (Proposed)

```prisma
enum ArcadeGameType {
  BLUEDONLE
  BIBLE_WORDLE
  SAINT_SCRAMBLE
  CROSSWORD
  SUDOKU
  MATH
  SCIENCE
  GEOGRAPHY
  IT
  BROADCASTING
  CIRCUIT
  MINI
  EDUCATIONAL
  ESCAPE_ROOM
}

model ArcadeDailyPuzzle {
  id          String         @id @default(cuid())
  schoolId    String         @map("school_id")
  gameType    ArcadeGameType @map("game_type")
  puzzleDate  DateTime       @map("puzzle_date") @db.Date
  payload     Json           // word, grid, answers
  difficulty  String
  @@unique([schoolId, gameType, puzzleDate])
}

model ArcadeSession {
  id          String   @id @default(cuid())
  userId      String   @map("user_id") @db.Uuid
  gameType    ArcadeGameType
  puzzleId    String?  @map("puzzle_id")
  score       Int?
  completed   Boolean  @default(false)
  xpEarned    Int      @default(0)
  playedAt    DateTime @default(now()) @map("played_at")
}

model ArcadeStreak {
  id          String   @id @default(cuid())
  userId      String   @unique @map("user_id") @db.Uuid
  currentDays Int      @default(0) @map("current_days")
  longestDays Int      @default(0) @map("longest_days")
  lastPlayDate DateTime? @map("last_play_date") @db.Date
  freezesLeft Int      @default(1) @map("freezes_left")
}

model CampusQuest {
  id          String   @id @default(cuid())
  schoolId    String   @map("school_id")
  slug        String
  title       String
  stops       Json     // ordered stop definitions
  activeFrom  DateTime @map("active_from")
  activeTo    DateTime @map("active_to")
}

model CampusQuestProgress {
  id          String   @id @default(cuid())
  questId     String   @map("quest_id")
  userId      String   @map("user_id") @db.Uuid
  stopsCompleted String[] @map("stops_completed")
  completedAt DateTime? @map("completed_at")
  @@unique([questId, userId])
}

model Tournament {
  id          String   @id @default(cuid())
  schoolId    String   @map("school_id")
  title       String
  startsAt    DateTime @map("starts_at")
  endsAt      DateTime @map("ends_at")
  theme       String
  leaderboard Json?
}

model PrizeWheelSpin {
  id          String   @id @default(cuid())
  userId      String   @map("user_id") @db.Uuid
  spinDate    DateTime @map("spin_date") @db.Date
  reward      Json
  @@unique([userId, spinDate])
}
```

## Part XVI — Design Checklist

1. **Fun serves learning** — Does this game teach something?  
2. **5-minute session** — Can they play on a phone between classes?  
3. **Streak ethics** — Forgiving enough to not harm mental health?  
4. **Faith respectful** — Bible/saint games approved by ministry?  
5. **Campus Quest safe** — Stops in public, supervised areas only?  
6. **Want to open** — Would they choose this over another scroll?
